# АИС киноцентра

Группа 4432, вариант 20.
Руководитель проекта — Усенков С.Д.

Цель проекта — подготовить АИС для ведения каталога фильмов и сеансов,
резервирования мест, продажи и возврата билетов.

Задачи проекта ведутся в Redmine. Руководитель назначает исполнителей
и принимает результаты. Исполнители переводят выполненные задачи на проверку.

Исходные файлы хранятся в GitHub. Изменения готовятся в отдельных ветках
и передаются на проверку через Pull Request в ветку develop.
