## Установленные компоненты

- Виртуализация: VirtualBox.
- ОС: Ubuntu 26.04.1 LTS.
- Redmine: 6.1.5, ручная установка из архива.
- Ruby: 3.3.8.
- Bundler: 2.6.7.
- PostgreSQL: 18.6.
- Веб-сервер: Puma 8.0.2.
- Git: 2.53.0.

## Размещение и запуск

Каталог приложения: /srv/redmine/app.
Служебный пользователь Linux: redmine.
База данных PostgreSQL: redmine.
Служба systemd: redmine-lab.
Автозапуск службы включён.
Адрес внутри ВМ: http://127.0.0.1:3000.

## Оформление

Создана и применена учебная тема lab_cinema.
Файл темы: themes/lab_cinema/stylesheets/application.css.

## Проверка

Подключение к PostgreSQL проверено SQL-запросом.
Начальные данные Redmine загружены.
Служба имеет состояние active (running).
Страница открывается в браузере, вход администратора выполнен.
Изменение оформления подтверждено визуально.

## Возникшая сложность

Puma был указан в тестовой группе зависимостей,
исключённой при установке. Для запуска приложения
Puma дополнительно подключён через Gemfile.local.
